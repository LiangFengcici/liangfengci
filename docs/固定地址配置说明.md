# 固定公网地址配置（ngrok 静态域名）

> 目的：让小程序连回的地址**永久不变**，从而「小程序只上传一次，以后不用再传」。
> 之前的 localhost.run 隧道每次重连都会换域名，一换就得重新上传小程序，不适合给老师长期用。
>
> ✅ `tools\ngrok\ngrok.exe` 已内置（v3.39.13），无需再下载。你只需要注册拿「token + 域名」。

---

## 一、只做一次：注册 + 领域名（约 3 分钟）

1. 打开 <https://dashboard.ngrok.com/signup>，用邮箱注册（免费，不需要信用卡）。
2. 登录后打开 <https://dashboard.ngrok.com/get-started/your-authtoken>，
   复制页面上的 **Authtoken**（一长串字母数字）。
3. 打开 <https://dashboard.ngrok.com/domains> → 点 **New Domain** →
   系统会送你一个免费的静态域名，形如：

   ```
   dental-lfc-xxxx.ngrok-free.app
   ```

   把它记下来（不要带 `https://`）。

> 免费账号：1 个静态域名、1 条同时运行的隧道。对本项目完全够用。

## 二、启动（每次开机后要开）

1. 先双击 **启动系统.bat**（跑后端，窗口别关）。
2. 再双击 **固定地址.bat**：
   - 第一次会问你两个东西：粘贴 authtoken、粘贴静态域名 →
     自动存到 `miniprogram/tools/ngrok_token.txt`、`ngrok_domain.txt`，以后不再问。
   - 它会自己建隧道、实测公网可达、把地址写进 `miniprogram/utils/config.js`，
     并把当前地址存到 `runtime/当前公网地址.txt`。
3. 窗口里最后会打印类似：

   ```
   固定地址：https://dental-lfc-xxxx.ngrok-free.app
   ```

   **这个窗口必须开着** —— 你的电脑就是服务器。

## 三、小程序那边（只做一次）

1. 微信开发者工具按 `Ctrl + B` 重新编译，首页顶部横幅应变成绿色：
   「已连接诊所后台 · 数据实时同步」。
2. 右上角「上传」→ 版本号填 `1.0.1` → 到微信公众平台「版本管理」把它设为**体验版**。
3. 老师扫体验版二维码，点右上角「···」→「打开调试」。
4. 验证同步：小程序里下一单预约 → 电脑上打开
   `https://你的域名/login`（账号 `front1`，密码 `123456`）→
   前台接待的今日队列里能看到这条预约。

> 因为域名固定，**以后重启电脑只要再跑一次「固定地址.bat」，地址不变，小程序不用重新上传。**

## 五、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 提示 `authentication failed` | authtoken 粘错或失效：删掉 `tools/ngrok_token.txt` 重跑 |
| 提示域名不可用 / 已被占用 | 域名填错，或有别的 ngrok 在跑；回 dashboard 核对 |
| 小程序还是离线模式 | `config.js` 里 `PROD_URL` 与当前地址不一致，重跑「固定地址.bat」 |
| 老师打开白屏 | 让老师点右上角「···」→「打开调试」 |
| 电脑休眠后连不上 | 电源设置里关掉睡眠；或唤醒后重跑「固定地址.bat」 |
| 想临时回本机调试 | `python miniprogram/tools/set_public_host.py --local` |
| 不想用 ngrok 了 | 双击「一键公网地址.bat」走 localhost.run（地址会变） |
