# 接口清单

统一响应体：`{"code": 0, "message": "ok", "data": {...}, "trace_id": "..."}`；
业务拒绝返回 HTTP 4xx + 非 0 code（409 余量冲突 / 422 业务校验 / 428 需知情同意）。
鉴权：`Authorization: Bearer <token>`（`/api/login` 下发）。

## 一、小程序 API（`/api/*`，供微信小程序患者端调用）

| 方法 | 路径 | 说明 | 关键参数 |
|---|---|---|---|
| POST | `/api/login` | 登录（code2session 模拟），返回 token / 患者档案 / 过敏史 | `code`（openid） |
| GET | `/api/catalog` | 项目目录（8 分类 18 项目，含时长/定金/是否需同意书） | — |
| GET | `/api/dentists` | 按「资质覆盖 × 当日已发布班次余量」过滤候选医生 | `catalog_id`, `date` |
| GET | `/api/availability` | 医生当日连续可约时段（30 分钟切片） | `catalog_id`, `dentist_id`, `date` |
| POST | `/api/booking` | 下单锁号（条件更新防超卖），支持 `Idempotency-Key` 头；`deposit=true` 同时生成定金单 | `catalog_id, dentist_id, clinic_id, date, start_time, allergens, note` |
| POST | `/api/pay` | 支付（幂等：重放返回首次结果）；返回 `pay_params` 供 `wx.requestPayment` | `invoice_id`, `amount_cents` |
| POST | `/api/pay/notify` | 支付回调（按第三方流水号幂等入账） | `third_party_no`, `amount_cents` |
| GET | `/api/bookings` | 我的预约（状态/金额/医生/门诊） | — |
| POST | `/api/booking/<vid>/cancel` | 取消预约（24h 分档退定金、释放号源） | — |
| POST | `/api/booking/<vid>/reschedule` | 改期（校验目标时段余量后原子换位） | `date`, `start_time` |
| GET | `/api/bills` | 结算单明细 + 分期计划 | — |
| GET | `/api/member` | 会员等级 / 积分 / 储值 / 优惠券 | — |
| GET | `/api/reports` | 报告与影像索引（脱敏） | — |
| POST | `/api/jobs/run` | 手动触发定时任务（Header `X-Job-Key`） | — |

## 二、员工端页面路由（RBAC 按 4.12 角色矩阵拦截）

**前台接待**（front1）
`/staff/frontdesk` 候诊队列 / `/staff/frontdesk/booking` 预约登记 / `arrive|cancel|reschedule|waitlist|pack/use|installment|refund` 各 POST 动作。

**医生工作站**（doc1/doc2）
`/staff/doctor` 我的诊室 / `/staff/doctor/visit/<vid>` 牙位图工作区；
`tooth|perio|plan|rx|imaging|consent|treatment|complete|finish` 病历各域 POST。

**财务工作台**（fin1）
`/staff/finance` 收款 / 退款审批 / 开票红冲 / 折扣审批 / 对账 / 审计。

**经营端**（mgr1 / ops1）
`/staff/manager` 看板 / `/staff/manager/schedule` 排班与号源 / `/staff/ops` 目录·资质·配额·库存。

## 三、患者端 H5 页面（小程序同构界面原型）

`/p/`（分类）→ `/p/item/<id>` → `/p/dentists` → `/p/slots` → `/p/confirm`（POST `/p/submit`）→ `/p/pay/<invoice_id>`；
`/p/bookings`（取消/改期） `/p/bills` `/p/member` `/p/reports`。

## 四、演示快捷入口（原型期，上线前移除）

`/demo/front` `/demo/doctor` `/demo/finance` `/demo/manager` `/demo/ops` `/demo/patient`，支持 `?next=/目标路径` 直接跳转。
