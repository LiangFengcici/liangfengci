# 云端部署指南 · 电脑关机老师也能用

> 适用场景：不想让「老师能不能打开」取决于你的电脑开不开机。
> 目标平台：PythonAnywhere 免费版（24 小时在线、HTTPS、不要备案、不要信用卡）。
> 部署包：`deploy/dental_cloud.zip`（已打好，含全部源码 + 演示数据库）。

---

## 一、注册（2 分钟）

1. 打开 <https://www.pythonanywhere.com/registration/register/beginner/>，用邮箱注册
2. **用户名要想好**：它决定永久地址 `https://用户名.pythonanywhere.com`
   （建议：`dentallfc` / `dentalliang` 这类，注册后不能改）
3. 邮箱验证

## 二、上传代码（3 分钟）

1. 登录后进 **Files** 标签 → 点 **Upload a file** → 上传电脑上的
   `D:\系统分析与设计\deploy\dental_cloud.zip`
2. 打开 **Consoles → Bash**，逐行执行：

   ```bash
   unzip ~/dental_cloud.zip -d ~/dental
   cd ~/dental/web
   mkvirtualenv dentenv --python=python3.10
   pip install -r requirements.txt
   ```

## 三、创建网站（5 分钟）

1. 进 **Web** 标签 → **Add a new web app** → Next（免费版域名固定为
   `你的用户名.pythonanywhere.com`）→ 选 **Manual configuration** → Python **3.10**
2. Web 标签页里找到 **Code** 区域，改两处：
   - **WSGI configuration file**（点开链接，把整个文件内容替换为下面这段，保存）：

     ```python
     import os
     import sys

     sys.path.insert(0, "/home/你的用户名/dental/web")
     os.environ.setdefault("DENTAL_NO_JOBS", "1")

     from app import app as application
     ```

     ⚠ 把两处 `你的用户名` 换成你注册时的用户名
   - **Working directory**：填 `/home/你的用户名/dental/web`
3. 同一页找 **Virtualenv** → 填 `/home/你的用户名/.virtualenvs/dentenv`
4. **Static files** 区域加一条映射：
   - URL：`/static/`　　Directory：`/home/你的用户名/dental/web/static`
5. 点绿色 **Reload** 按钮

## 四、验证（1 分钟）

浏览器打开 `https://你的用户名.pythonanywhere.com/login`
→ 应看到牙科平台登录页 → `front1 / 123456` 进前台接待。

## 五、切换小程序到云端（我来做）

把你的用户名（或完整网址）发我，我执行：

```bash
python miniprogram/tools/set_public_host.py https://你的用户名.pythonanywhere.com
```

然后开发者工具 `Ctrl+B` 验证胶囊变绿 → 上传 `1.0.2` → 设为体验版。
**从此电脑关不关机都不影响老师使用。**

## 注意事项

- **数据分家**：云端用的是上传时那份演示库，之后小程序/老师产生的数据都存在云端；
  你本机 `127.0.0.1:8000` 的数据不会自动同步过去。建议以后**只用云端地址**。
- **免费版限制**：3 个月不登录控制台会被回收（登录一次即可）；只开 1 个 web app；
  流量 5GB/月（演示绰绰有余）。
- **定时任务**：云端 WSGI 模式下关闭了进程内定时任务（对账/汇总由演示库自带数据支撑）。
- **性能**：免费版是共享 CPU，单人演示完全够用，并发多了会慢。
