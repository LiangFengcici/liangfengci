# 二维码更新操作卡（体验版 7 天有效期的应对）

## 背景

- **体验版本身**：不设过期时间，只要账号正常、扫码者在「体验成员」名单内，一直可用。
- **体验版二维码**：有效期约 **7 天**（生成时页面会提示「该二维码 X 月 X 日前有效」），过期后扫码提示「体验码已过期」。

## 三层保障（按顺序兜底）

1. **扫一次，之后从列表进**：老师首次扫码成功后，小程序会留在微信首页下拉「最近使用」和「发现—小程序」里，之后直接点开即可，**不再依赖二维码**。→ 只需保证老师第一次打开时码在有效期内。
2. **取码页（地址永久不变）**：`https://liangfengci.pythonanywhere.com/static/qr.html`
   页面里显示的是当前有效的二维码；二维码到期换一张图即可，地址和文档都不用改。
3. **文档里的入口码（图 B-1）**：报告附录 B.2 里那张二维码指向取码页，**永不过期**。老师扫它 → 打开取码页 → 再扫页内最新码。

> 注意区分两张图，别混：
> - `docs\qr_entry.png` = **入口码**，只贴在报告里，指向取码页，**不要上传**到网站。
> - `qr.png` = **体验版二维码**，从微信公众平台下载，上传到网站给取码页展示。两者搞反会变成「扫了又回到取码页」的死循环。

## 第一次：把取码页传上云端（2 分钟）

**第 0 步：先拿到体验版二维码图片**

1. 电脑浏览器打开 `https://mp.weixin.qq.com`，登录小程序账号（管理员微信扫码）
2. 左侧菜单「管理」→「**版本管理**」
3. 页面往下找「**体验版**」区块（不是"开发版本"）。如果还没有体验版，先在「开发版本」里选一个版本点「选为体验版」
4. 体验版那一行右侧点「**二维码**」，弹出二维码图片 → 在图片上**右键 → 图片另存为**
5. 保存到桌面，文件名改成 `qr.png`

**第 1 步：打开云端的静态目录**

浏览器打开（建议先右键 →「恢复成原始网页」，避免翻译把路径改坏）：

```
https://www.pythonanywhere.com/user/liangfengci/files/home/liangfengci/dental/web/static
```

**第 2 步：上传两个文件**

点页面上方的蓝色「**Upload a file**」按钮：

- 第一个：本机 `D:\系统分析与设计\web\static\qr.html`
- 第二个：刚保存的 `qr.png`（桌面）

每次选一个文件，传完会回到文件列表，再点一次上传另一个。传完列表里应该能看到 `qr.html` 和 `qr.png`。

**第 3 步：验证**

浏览器打开 `https://liangfengci.pythonanywhere.com/static/qr.html`，应该看到牙科平台的取码页，中间是你刚传的二维码。手机微信扫一下，能进小程序就通了。

- 页面显示"二维码尚未上传" → `qr.png` 没传成功，或没传在这个目录
- 页面 404 → `qr.html` 没传成功
- 页面出来了但图片刷不出来 → 按 `Ctrl + F5` 强制刷新（静态文件有缓存）

## 以后每次更新（码过期前，2 分钟）

1. 微信公众平台 → 版本管理 → 体验版 → 再次点「**选为体验版**」（版本号不用变、代码不用重传），弹出新二维码
2. 右键保存，改名 `qr.png`
3. 上传到同一个云端目录，**覆盖**旧的 `qr.png`
4. 完成。取码页立刻显示新码，文档里的入口码不用动

## 提醒

- 交作业/答辩**前一天**更新一次码，保证 7 天窗口覆盖提交和批阅初期。
- 老师还没扫码就过期的情况：让他扫文档里的图 B-1（永久入口码）。
- 页面图片有缓存，更新后让老师**刷新**取码页即可。
