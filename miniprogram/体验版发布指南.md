# 微信小程序 · 体验版发布指南（不上线给老师用）

> 结论先行：**体验版不需要通过审核**。审核没通过完全不影响把小程序交给老师使用。
> 也不用开通腾讯云——本项目用的是普通 HTTP 接口，与云开发无关。

## 整体路线（你现在的位置 → 目标）

```
[已完成] 小程序代码 + 离线演示兜底（接口连不上时自动用内置演示数据，界面完整可走全流程）
    ↓
第 1 步  添加老师为「项目成员 + 体验成员」      ← 微信公众平台后台，10 分钟
第 2 步  上传代码 → 设为体验版 → 生成体验二维码  ← 开发者工具 + 后台，5 分钟
第 3 步  老师扫码 → 打开调试模式 → 完整体验      ← 老师手机上 1 分钟
    ↓
（可选）第 4 步  内网穿透，让老师看到「真实后端数据」而不是演示数据
```

## 第 1 步：把老师加进来（mp.weixin.qq.com）

1. 浏览器打开 **mp.weixin.qq.com**，用小程序管理员微信扫码登录
2. 左侧「**管理 → 成员管理**」：
   - **项目成员** → 添加成员 → 输入老师微信号 → 老师在他手机上确认 → 勾选「开发者」「数据分析」等权限
   - **体验成员** → 同样把老师微信号加上（这一步决定他能不能扫体验二维码）
3. （可选）「开发管理 → 开发设置」里无需改动

> 老师收到确认通知后点一下同意即可。小程序「成员」上限充足，个人主体也能加。

## 第 2 步：换上自己的正式 AppID（上传前必须做）

如果点「上传」提示 **「测试号 AppID 无法上传，请使用正确的 AppID」**，是因为项目导入时
选成了「测试号」——测试号只能本地预览，**任何情况下都不能上传**。解决：

1. **拿到正式 AppID**
   浏览器登录 https://mp.weixin.qq.com （用注册小程序的那个微信）→ 左侧「管理 → 开发管理 → 开发设置」
   → 页面顶部「开发者ID」里的 **AppID(小程序ID)**，形如 `wx1a2b3c4d5e6f7890`
   （18 位，别复制旁边的 AppSecret）

2. **写进项目**（两选一）
   - 双击 `D:\系统分析与设计\设置AppID.bat`，粘贴 AppID 回车即可
   - 或开发者工具 → 右上「详情 → 基本信息 → AppID」→ 点「**修改**」→ 选「输入 AppID」→ 粘贴

3. 开发者工具提示重新打开时点「确定」，按 `Ctrl+B` 重新编译

> 若在后台找不到 AppID、提示「未完成注册」：说明小程序注册流程（主体信息、管理员验证）
> 还没走完。必须先完成注册才有 AppID 和上传权限。个人主体可以注册，但「医疗服务」类目
> 审核会比较难——**体验版不需要审核，注册完能上传就够答辩用了**。

## 第 3 步：上传并发布体验版

1. 微信开发者工具打开本项目 → 右上角点「**上传**」
   - 弹出的是「版本号 / 项目备注」小窗，**上传本身不需要扫码**（若弹登录二维码，说明工具登录过期，扫一下即可）
   - 填版本号：`1.0.0`，备注：`患者端完整预约流程`
   - 上传前确认 `utils/config.js`：`fallbackMock: true` 保持开启（老师无后端也能看）
2. 登录 mp.weixin.qq.com → 「**版本管理**」→ 找到刚上传的「开发版本」→ 点「**选为体验版**」
3. 体验版卡片上点「**二维码**」→ 保存图片

## 第 4 步：老师手机上的操作（发这段给老师即可）

> 老师操作：① 用微信扫体验版二维码 → 打开小程序；
> ② 点右上角「···」→ **打开调试** → 小程序自动重启；
> ③ 重新进入，即可完整使用（页面顶部出现 vConsole 悬浮球属正常现象，是调试标识）。
>
> 「打开调试」这一步的作用是跳过域名校验，让未配置合法域名的演示环境也能加载数据。

## 关于「看到什么数据」的两种模式

| 模式 | 老师看到的 | 需要的条件 |
|---|---|---|
| **离线演示**（当前默认） | 完整界面 + 内置演示数据（项目/医生/时段/预约/账单/会员/报告全部可交互，重启后数据重置） | 无需任何服务器，扫码即可 |
| **真实数据** | 与电脑上员工端联动的真实库数据 | 你的电脑跑着后端 + 内网穿透出公网地址（见下） |

## 先说明：体验版「分享不了给别人」是正常的

体验版有个硬限制：**二维码 / 转发卡片只有「体验成员」和「项目成员」能打开**，
别人扫了会提示「暂无权限」。所以：

| 你想做的事 | 可行吗 | 怎么做 |
|---|---|---|
| 老师体验 | ✅ 可以 | 把老师加为**体验成员**，发体验版二维码 |
| 转发给同学让他随便看 | ❌ 不行 | 除非把他加成体验成员（未认证小程序体验成员约 20 人上限） |
| 任何人扫码就能用、能转发 | ❌ 不行 | 必须**发布上线**（→ 提交审核 → 审核通过 → 发布），这一步才叫"上线" |

**所以「分享不了」不是 bug，是体验版的设计。** 你的目标是不上线给老师用，加体验成员就够了。

## （可选）第 5 步：内网穿透，让小程序连回你的牙科平台

不做这步也能用，但数据是**内置演示数据**（重启重置，与电脑上的平台无关）。
做了这步，小程序里的预约/支付会真实写进 `D:\系统分析与设计\web\data\dental.db`，
电脑上的员工端能立刻看到——答辩时这个联动最有说服力。

### 方式 A：一键脚本（推荐，零注册、零下载）

前提：Windows 10/11 自带 OpenSSH 客户端（一般都有）。

1. 先双击 `启动系统.bat`，让后端跑起来，**这个窗口不要关**
2. 双击 `D:\系统分析与设计\一键公网地址.bat`
   - 脚本会自动建立 SSH 隧道，秒出地址：`https://xxxxxxxx.app.lhr.life`
   - 自动实测该地址的 `/api/catalog`，通了才写进 `utils/config.js`（`ENV='prod'`）
3. 微信开发者工具 `Ctrl+B` 重编译 → 首页状态条变「已连接诊所后台 · 数据实时同步」
4. 重新上传（版本号加一）→ 后台设为体验版 → 新二维码给老师

**注意**：`一键公网地址.bat` 的窗口要一直开着，关掉公网地址立即失效（小程序退回离线演示）。
下次重开脚本会拿到**新地址**并自动改写配置，但要**重新上传一次版本**（地址写在代码里）。

> 用的是 localhost.run 的免费匿名隧道，无需账号；免费隧道地址不固定，适合答辩与短期分享。

### 方式 B：cpolar / natapp（地址相对稳定，需注册）

1. 注册 cpolar（https://www.cpolar.com）或 natapp（https://natapp.cn），免费版够用
2. 下载 Windows 客户端，在解压目录开 cmd：
   ```
   cpolar authtoken 你的token
   cpolar http 8000
   ```
   窗口会打印一行 `https://xxxx.cpolar.top -> http://localhost:8000`，复制 https 那个地址
3. **双击 `D:\系统分析与设计\设置公网地址.bat`**，粘贴地址回车。脚本会：
   - 校验地址（拒绝局域网 IP 和 `100.x` NAT 网段）
   - 从本机实测 `<地址>/api/catalog`，通了才写入
   - 写入 `utils/config.js`：`ENV = 'prod'`，`PROD_URL = 'https://xxxx.cpolar.top'`
4. 开发者工具 `Ctrl+B` 重编译 → 首页顶部状态条变「**已连接诊所后台 · 数据实时同步**」
5. 重新上传（版本号加一）→ 后台设为体验版 → 换新二维码给老师

**验证数据真的同步了**：
- 小程序里下一单（项目 → 医生 → 时段 → 付定金）
- 电脑上打开 `http://127.0.0.1:8000/login`，用 `front1 / 123456` 登录
- 「前台接待」当天的候诊队列里能看到这条，患者姓名是「周若彤」

**想切回本机调试**：双击 `设置公网地址.bat` → 或命令行执行
`python miniprogram\tools\set_public_host.py --local`

> 注意：免费版穿透地址重启后会变，变了重跑 `设置公网地址.bat` 粘贴新地址即可（30 秒）。
> 穿透域名不是你自己的备案域名，**无法**填进小程序后台的「服务器域名」白名单——
> 所以老师必须保持「打开调试」状态才能访问。这是体验版的常见做法，不影响答辩。


## 找不到体验版二维码？先认清「版本管理」页面的三个区块

登录 mp.weixin.qq.com →「管理 → 版本管理」，页面从上到下是：

```
┌ 线上版本 ──────────── 已发布给所有人的版本（你现在应该是空的）
├ 审核版本 ──────────── 提交过审核的版本；被驳回的会停在这里
├ 开发版本 ──────────── 开发者工具最近一次「上传」的版本
└ 体验版本 ──────────── 设为体验版之后，这里才有「二维码」按钮
```

**关键规则：只有「开发版本」里的版本能「选为体验版」。** 一旦你把某个版本提交了审核，
它就从「开发版本」挪到「审核版本」，**审核版本（含被驳回的）永远不能设为体验版**。
所以如果你先前提交过审核（被驳回），现在「开发版本」是空的 → 没有「选为体验版」按钮 → 拿不到二维码。

**解法：回开发者工具重新「上传」一次**，新版本会重新出现在「开发版本」里，
这时「选为体验版」就是可点的了。

| 看到的现象 | 含义 | 处理 |
|---|---|---|
| 「开发版本」为空，只有「审核版本」有记录 | 版本已提交审核，不在开发版本位 | 重新上传一次，再用新版本设体验版 |
| 「开发版本」有记录但「选为体验版」是灰的 | 该版本正在审核中，或被其他成员上传的版本取代 | 重新上传最新代码后再设 |
| 点「选为体验版」无反应 | 账号不是管理员，或小程序注册未完成 | 换管理员微信登录；未注册完先完成注册 |
| 已设体验版但「二维码」点不开 | 浏览器拦截弹窗 | 换 Chrome/Edge，或允许弹窗；也可直接下载二维码图片 |

**临时兜底（不想折腾体验版时）**：开发者工具右上角「**预览**」也会生成一个二维码，
手机微信扫码即可打开——但它有两个限制：① 只有「项目成员」能扫（老师得先在成员管理里加上）；
② 二维码 25 分钟后失效，每次演示前要重新生成。所以只适合当下自测，不适合交给老师长期用。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 上传时提示「测试号 AppID 无法上传」 | 项目用的是测试号（`touristappid` 或工具自动分配的测试 appid） | 回到第 2 步换成正式 AppID |
| 上传时提示「请先绑定开发者」/ 扫码后无权限 | 扫码的微信号不是管理员或项目成员 | 用注册小程序的那个微信扫码，或先在「成员管理」加为开发者 |
| 老师扫码提示「暂无权限」 | 没加为体验成员 | 回到第 1 步第 2 小步 |
| 转发给同学打不开 / 提示无权限 | 体验版只对体验成员开放 | 正常限制；要么把他也加成体验成员，要么发布上线 |
| 打开是白屏 / 一直加载 | 体验版没开调试，请求被域名校验拦截 | 右上角「···」→ 打开调试 |
| 首页显示「离线演示模式」 | 接口不可达，自动降级 | 点状态条可看原因；要真实数据走第 5 步 |
| 已经配了公网地址仍显示离线 | 穿透窗口关了 / 地址变了 / 后端停了 | 重开穿透，重跑 `设置公网地址.bat` 粘贴新地址 |
| 提示「登录已失效，请重新进入」 | 切换了接口地址，旧 token 属于上一个环境 | 正常（已按环境隔离缓存），退出重进即可 |
| 提示网络错误且无 vConsole | 老师微信版本过旧 | 让老师把微信更新到最新版 |
| 我自己真机调试也白屏 | baseUrl 还是 127.0.0.1 | 双击「设置真机IP.bat」按热点方案配置 |

## 答辩/检查现场建议

- **保底方案**：断网也能演示 → 现在的离线模式就是为此准备的，真机上永远能走完流程
- **加分方案**：现场手机热点 → 电脑 `python run.py` → 「设置真机IP.bat」→ 真机看到与员工端联动的真实数据（在员工端收一位患者，患者端账单立刻变化，最有说服力）
